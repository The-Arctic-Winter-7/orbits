# Orbits
You are a star! Literally.

<p>As a star, you have your own gravitational pull, and you can summon planets to orbit you, even as
you move around. However, the more planets you summon, the more likely they are to collide with each other!
When two planets collide, they are deleted, leaving you with two less planets orbiting you.</p>

<p>This is mainly a tech demo project, so think of it as an interactive simulation rather than a game.</p>

## Controls
<p>Press A (X if using mGBA) to summon planets.</p>
<p>Press B (Z if using mGBA) to delete the youngest planet.</p>
<p>Press START (Return / Enter if using mGBA) to clear the screen.</p>
